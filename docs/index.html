DataMiner

Una araña por cada criterio de búsqueda.

Escribes un término y DataMiner lo busca a la vez en 20 fuentes: buscadores, prensa mundial, redes, foros, código, ciencia y archivos. Se queda solo con lo reciente, extrae el contenido limpio de cada página y descarga los ficheros enlazados (PDF, CSV, XLSX…). Todo queda en tu equipo.

Descargar para Windows Ver el código

Versión 2.0.0 · Windows 10/11 · Sin instalación, sin cuenta, sin nube.

Qué hace

Busca en paralelo

Lanza el término a la vez en buscadores, noticias, redes, repositorios y catálogos abiertos, con variantes y operadores (filetype:, intitle:, site:).

Solo lo reciente

Por defecto, los últimos 7 días. Se aplica en origen y otra vez sobre la fecha extraída. Lo que no trae fecha se marca como tal.

Texto limpio en Markdown

Cada página se guarda con su autor, fecha, sitio y enlaces, lista para leer o procesar.

Ficheros enlazados

Descarga PDF, CSV, XLSX, ZIP y más, con su SHA-256. Los PDF también se convierten a texto.

Mapa de hallazgos

Agrupa lo encontrado por tema, dominio o fuente y lo dibuja en un mapa interactivo con tres niveles de zoom.

Vigilancias

Guarda búsquedas que se repiten solas mientras la app está abierta y te muestra únicamente lo nuevo.

Descargar

  1. Descarga el zip desde Releases (DataMiner-2.0.0-windows.zip).
  2. Descomprímelo en la carpeta que quieras.
  3. Abre DataMiner.exe. No necesita Python ni instalación.

Tus datos se guardan en %USERPROFILE%\DataMiner\output\.

Desde el código

git clone https://github.com/virtuanista/DataMiner.git
cd DataMiner
python -m venv .venv
